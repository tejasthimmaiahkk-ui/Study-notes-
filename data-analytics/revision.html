One-page theory summary (Units I & IV)

  • Analytics = examine data to support decisions. DIKW pyramid.
  • Evolution: statistics → databases/SQL → BI & warehouses → data mining → big data → AI.
  • Descriptive (what) · Diagnostic (why) · Predictive (what will) · Prescriptive (what should).
  • Benefits: decisions, customers, efficiency, revenue, risk, competitive advantage.
  • Text analytics: tokenise → stop words → stem → TF-IDF → sentiment/topics/NER.
  • Web analytics: sessions, bounce rate, conversion rate, CTR, A/B testing; on-site vs off-site.
  • Skills: SQL, Excel, Python/R, BI tools, statistics, domain, communication.
  • BI: sources → ETL → model → analysis → dashboards.
  • Power BI Desktop (.pbix, author) → Publish → Service (share, dashboards, refresh) → Mobile.
  • Views: Report, Table, Model. Panes: Filters, Visualizations, Data.
  • Get data: Excel, Web, SQL Server, etc.; Import vs DirectQuery.
  • Power Query: Applied Steps (M); remove/rename columns, remove rows, types, replace, split; Merge (join kinds) vs Append (union).
  • Visuals: bar/column, line, pie/donut, map, table, matrix, card, gauge, KPI, slicer.
  • Interactivity: slicers, filters (visual/page/report), cross-filter, drill-down, drill-through + back button, tooltips, bookmarks + buttons.

Mixed self-test

1. Which analytics type uses optimisation to recommend actions?

  1. Predictive
  2. Prescriptive
  3. Diagnostic
  4. Descriptive

Prescriptive = "what should we do".

2. Σx² = 40, Σy² = 90, Σxy = 54. r =

  1. 0.75
  2. 0.85
  3. 0.9
  4. 0.6

54/√3600 = 54/60.

3. For N = 6, ΣD² = 14, Spearman's R =

  1. 0.6
  2. 0.4
  3. 0.8
  4. 0.2

1 − 84/210 = 0.6.

4. If r = 0.5, σx = 4, σy = 8, then byx =

  1. 0.25
  2. 2
  3. 0.5
  4. 1

0.5 × 8/4.

5. A card is drawn: P(red or king) =

  1. 30/52
  2. 28/52
  3. 26/52
  4. 32/52

26 + 4 − 2 = 28.

6. Binomial with n = 5, p = 0.5: P(X = 2) =

  1. 5/32
  2. 1/32
  3. 10/32
  4. 15/32

5C2/32.

7. Poisson with m = 1: P(X = 0) ≈

  1. 0.368
  2. 0.5
  3. 0.135
  4. 1

e⁻¹.

8. X ~ N(50, 5²): P(X > 60) ≈

  1. 0.1587
  2. 0.0013
  3. 0.4772
  4. 0.0228

z = 2 → 0.5 − 0.4772.

9. In one-way ANOVA with 4 groups and 20 observations, df (within) =
