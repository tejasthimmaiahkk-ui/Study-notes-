1.1 Why drones need AI

The course (Lectures 1–3) covers three jobs an autonomous drone must do: perception (detect, track and understand the scene), mapping (build 3-D models and localise itself) and control/decision-making (plan and act, alone or in a swarm).

Applications listed in the lectures

  • Precision agriculture — soil mapping, crop life-cycle, spraying pesticide/fertiliser/seeds.
  • Large-area mapping — Digital Surface Model (DSM) generation, HD maps, VR, change detection with 3-D reconstruction.
  • Surveillance — traffic management, target detection and multi-object tracking (RGB and thermal/IR, day and night).
  • Aerial survey — topography maps.
  • Power-line and infrastructure inspection.
  • Disaster management — forest-fire fighting with swarms, flood change detection.
  • Swarms — perimeter defence, convoy protection, confinement escape, border surveillance, search and rescue, target tracking.

Why plain programming is not enough

  • Operational challenges: cluttered environments, domain change (day → night, RGB → IR), absence of data in the sensing domain.
  • Perception challenges: multiple sensors (RGB, IR, SAR, multispectral, LiDAR, event), few samples or none, domain/sensor shift, image enhancement, long-range perception.
  • Long-range / slant-angle perception: occlusion and scale change, domain shift, missing data (a future class may exist only as text), need for explainable AI.
  • Decision challenges: choice of sensor, cooperation and coordination in swarms; sensor, computation and communication uncertainty.

Deep-learning success = big data + GPUs + neural-network algorithms

Where the field is heading (Lecture 1a)

  • Multi-modal perception: RGB, depth, event cameras and LiDAR carry complementary information; problems include sim-to-real, domain generalisation, missing modalities and sensor failure.
  • Generative AI fixes data scarcity — e.g. generating IR images from RGB with diffusion models, because ordinary augmentation may break the physics of the imaging sensor.
  • Vision–language models (e.g. CLIP, pre-trained on 400 M image–text pairs): better out-of-distribution performance but lower in-domain performance. Vision-only ImageNet models: better in-domain, worse out-of-domain.
  • Foundation models for LiDAR and driving, Vision-Language-Action (VLA) models (generalist robot policies), end-to-end navigation (sensors → control commands), and the open goal of general intelligence.

1.3 AI, ML and DL — and hand-crafted vs learned features

Artificial Intelligence — the simulation of human intelligence processes by a computer: learning, reasoning, perception (scene understanding from multi-modal sensors), problem solving, language understanding.

Machine Learning — the system learns from data, improving without being programmed for every rule; finds patterns and predicts outcomes on new data.

Deep Learning — artificial neural networks with many layers that learn complex patterns.

Building blocks and architectures

Neurons receive, process and pass on signals. Weights are the strengths of connections, learned from data. Activation functions are nonlinear functions that define the nature of a neuron. The learning paradigm is the process of updating the weights.
Shallow networks: general prediction/classification. CNNs: images and video. Recurrent: Memory Neuron Network (MNN), LSTM, Transformer. Generative: GAN, diffusion models.
Traditional pipeline: raw data → expert-designed features → prediction. Feature extraction transforms raw data into a reduced set of features that describe it — time-consuming and not scalable.
Deep learning: raw data → prediction; the network progressively extracts higher-level features (low-level → mid-level → high-level) and turns them into a concise representation automatically.
Deep learning needs lots of labelled data and compute, and its features are harder to interpret.

1.4 What is a neural network?

A neural network is a massively parallel distributed processor made up of simple processing units that has a natural ability to store knowledge. Knowledge is acquired from data through a learning process, and stored in the inter-neuron connection strengths — the synaptic weights.

Inspiration: the human brain

  • ~1011 interconnected neurons, ~104 connections per neuron.
  • Each neuron is slow (milliseconds) but computation is massively parallel, with distributed representation.
  • Key properties: adaptability, self-organisation, generalisation, fault tolerance.

Properties of artificial networks

  • Nonlinearity — made of nonlinear neurons.
  • Input–output mapping — learns complex relations between input and output vectors.
  • Adaptivity — weights adapt when the relationship changes.
  • Fault tolerance — damage to one neuron/weight degrades performance gradually, not abruptly (distributed storage).

Information flowOne direction: input → layer 1 → … → outputHas cycles: a layer feeds back to itself or an earlier layer

1.5 What is learning, and when should we use it?

"A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
Example: T = detect vehicles in drone video, P = recall/precision, E = labelled video frames.

Use learning when…

  • No explicit rule can be written (language, image recognition).
  • The environment changes continuously (autonomous driving, markets).
  • Large data with hidden patterns (medical images, transactions).
  • Personalisation is needed (recommendation systems).
  • Human experts are unavailable or don't scale (protein folding).

Don't use learning when…

The rules are clearly defined (just code them), or the data is biased (the model will learn the bias).

1.7 Data for learning and normalisation

The true distribution of the data, and the true input–output relationship (e.g. Y = β0 + β1X), are unknown. We draw a random sample and fit an estimate ŷ = β̂0 + β̂1X + ε. Training and test data are assumed drawn independently from the same distribution (i.i.d.).
This assumption is exactly what breaks in drone imagery: a model trained on ground-level, daytime RGB images is tested on top-down, night-time or IR images — a distribution (domain) shift.
Normalise inputs (e.g. z = (x − μ)/σ): activations become symmetric, gradients smoother, and neurons avoid saturation (the flat tails of sigmoid/tanh, Week 3).
Normalisation is a linear rescaling — it does not change the shape of the distribution (Week 6 assignment).

1.8 Evaluation metrics

Regression

MSE = (1/n) Σ (yi − ŷi)²  ·  RMSE = √MSE  ·  R² = 1 − SSres/SStot, where SSres = Σ(yi − ŷi)², SStot = Σ(yi − ȳ)²

R² is the fraction of the variance of y explained by the model — closer to 1 is better.

Classification

OutcomeMeaningLecture example
TPPredicted positive, actually positiveWildfire sensor alarms during a real fire
TNPredicted negative, actually negativeTest says "negative" for a healthy patient
FP — Type I errorPredicted positive, actually negative (false alarm)Motion sensor triggered by a stray cat signals "intruder"
FN — Type II errorPredicted negative, actually positive (miss)Metal detector stays silent for a concealed weapon

Accuracy = (TP + TN)/N  ·  Precision = TP/(TP + FP)  ·  Recall = TP/(TP + FN)  ·  F1 = 2·P·R/(P + R) (harmonic mean)

Precision divides by the predicted positives (column), recall by the actual positives (row). The Week 1 assignment's wrong option swapped them. Also: on imbalanced data a "predict everything negative" model has high accuracy but zero recall.

1.9 Linear-algebra foundations: combinations, span and independence

The lectures list "vectors, matrices, optimisation" (Gilbert Strang, Linear Algebra and its Applications) as the prerequisite, and the Week 1 assignment tests it.

A linear combination of v1…vk is w1v1 + … + wkvk = Xw (the v's are the columns of X). The span is the set of all such combinations. The vectors are linearly independent if Xw = 0 has only the trivial solution w = 0; otherwise they are dependent.
A neuron's net input Σwixi is a linear combination; a layer's output is Wx. Redundant (dependent) features add nothing new.
Linear Dependence Lemma: if v1…vk is dependent and v1 ≠ 0, some vi (i ≥ 2) lies in the span of the others, and removing it leaves the span unchanged.
Rank = number of independent columns. More than n vectors in ℝn are always dependent. Independent vectors need not span ℝn (e.g. 2 independent vectors in ℝ3 span only a plane), and X need not be square.
With measured (noisy) data, exact dependence is rare; "nearly dependent" columns make solutions unstable.

1.10 Why ground-level models fail on aerial images

ImageNet / COCO images

  • Objects large, centred, upright.
  • Eye-level, side-on viewpoint (a dog fills the frame; a car seen from the side).
  • Moderate scale variation.

Drone / satellite images

  • Top-down or slant viewpoint.
  • Objects small and densely packed.
  • Arbitrary orientations.
  • Large scale variation between near and distant objects; occlusion.
  • Often other modalities (IR, SAR, multispectral) and night/weather changes.

When asked why a model trained on ground-level data underperforms on aerial data, choose the option about the training distribution not representing small, dense, rotated, top-down objects. Reject options blaming colour vs greyscale, number of classes, speed or GPU memory.
