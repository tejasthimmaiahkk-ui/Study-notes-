6.1 Why normalise inputs?

Non-zero-centred inputs (e.g. all positive, as after a sigmoid) make all gradients of a neuron's weights share a sign → zig-zag updates and slow training (see 3.1). Scale mismatch — one feature in [0, 1], another in [0, 10,000] — makes the loss landscape elongated and ill-conditioned, giving uneven gradients.
Making E[x] = 0 lets ∂L/∂w take either sign. Gradient descent works best when features are centred at zero with comparable variances; if the Hessian is close to the identity matrix, the problem is much easier (LeCun et al., "Efficient BackProp").
Weight initialisation assumes standardised inputs: Xavier/Glorot uses Var(y) = n·Var(w)·Var(x) with Var(w) = 1/n (fan-in n), so Var(y) ≈ 1 only if Var(x) ≈ 1. With much larger input variance, activations and gradients can explode.
Z-score normalisation z = (x − μ)/σ is a linear rescaling: it shifts and stretches the values but preserves the shape of the distribution (skewness and kurtosis unchanged).

6.2 Internal covariate shift

Internal covariate shift: as earlier layers' weights change during training, the distribution of inputs to each later layer keeps changing from batch to batch, even though the training data does not. Each layer must keep re-adapting.
Problems: slower training (time spent adapting rather than learning features); need for lower learning rates; sensitivity to initialisation; vanishing/exploding gradients.
Standard fix: Batch Normalisation (Ioffe & Szegedy, 2015). Not to be confused with dataset covariate shift (train vs test inputs differ — fixed by augmentation/adaptation) or label shift.

Training vocabulary: an iteration = one forward + backward pass and one weight update on one batch of B samples; an epoch = one pass over the whole dataset = (total samples / batch size) iterations. A feature map is stored as [B, C, H, W].

6.3 Batch, Layer, Instance and Group Normalisation

x̂ = (x − μ)/√(σ² + ε), then a learnable affine transform y = γx̂ + β (γ, β per channel). The methods differ only in which values share μ and σ.

Methodμ, σ computed overKey facts
Batch Norm(N, H, W) — per channel, across the batchRobust to initialisation; zero overhead at test time. Behaves differently in training and testing (a common source of bugs): training uses mini-batch statistics, inference uses running averages with γ, β frozen — BN then becomes a linear operator.

Group Norm(C/G, H, W) — per sample, per group of channelsG = 32 by default. G = 1 → LN (assumes all channels contribute similarly); G = C → IN (uses only spatial statistics, missing channel dependence). Wu & He, 2018.

6.4 Style vs content, AdaIN and normalisation perturbation

Content = spatial structure (edges, shapes, lines) — the pattern of activations across H × W. Style = channel statistics: the mean μ (overall brightness/tone) and std σ (contrast/spread) of each channel — the texture. Two images with the same per-channel μ and σ look stylistically similar even if their layouts differ (e.g. "cool cinematic" μ = [60, 100, 160] vs "golden hour" μ = [220, 160, 60]).
Instance Norm in style transfer: it strips each image's own contrast/intensity statistics, so the generator can impose the target style — replacing BN by IN noticeably improves stylisation.
AdaIN (Huang & Belongie, 2017): AdaIN(x, y) = σ(y)·((x − μ(x))/σ(x)) + μ(y) — normalise the content features, then scale and shift them with the style image's channel statistics. Arbitrary style transfer in a single forward pass, no iterative optimisation.
Normalisation perturbation (Fan et al., 2022): randomly perturb the channel statistics of feature maps during training to simulate style/domain changes — a simple domain-generalisation method for real-world domain shifts (e.g. day/night, weather in drone imagery).

6.5 Looking inside a CNN

Domain of dependence (receptive field): with 3 × 3 filters, a neuron in one layer depends on a 3 × 3 patch of the layer before, a 5 × 5 patch two layers back, and so on — each stride-1 3 × 3 layer adds 2 (RL = RL−1 + k − 1). Pooling enlarges it faster.
Hierarchy of learned features (Zeiler & Fergus): first layers — edges, corners, small textures; intermediate — parts (eyes, nose); deep — whole objects (faces, cars, cats).
DeConvNet maps activations from deep layers back to pixel space: (i) unpool (reverse max-pooling using the recorded "switch" locations, preserving the stimulus structure), (ii) rectify, (iii) filter with the transposed learned filters. A DeConvNet has no learning stage.
What ZFNet's visualisation showed (ImageNet validation set, top-9 activations per feature): layer 1 — oriented edges and colours; layer 2 — corners and edge/colour conjunctions; layer 3 — more complex patterns (mesh, wheel, text); layer 4 — dog faces, birds' legs; layer 5 — whole objects with large pose variation. Small transformations change layer-1 features a lot but the top layers much less (quasi-linear for translation and scaling).

6.6 Interpretability: saliency, CAM and Grad-CAM

Why explain? (1) When AI is weaker than humans — to identify failure modes; (2) on par — to build user confidence; (3) stronger — for machine teaching. There is a trade-off between accuracy and interpretability (200-layer ResNets are accurate but opaque).
Saliency map (Simonyan et al., 2013) — pixel attribution: approximate the class score Sc(I) near the image I0 by a first-order Taylor expansion, Sc(I) ≈ wTI + b with w = ∂Sc/∂I at I0; the magnitude of w per pixel is the heat map. Needs a single backpropagation pass.
CAM — maps the predicted class score back to the last conv layer to highlight discriminative regions; requires a restricted architecture (global average pooling before the classifier).
Grad-CAM (Selvaraju et al., 2017): (1) choose image and class c; (2) forward pass → score yc before softmax; (3) pick the target conv layer with maps Ak; (4–5) compute ∂yc/∂Ak and the neuron-importance weights by global average pooling: αkc = (1/Z) ΣiΣj ∂yc/∂Akij (Z = u × v); (6) weighted combination Σk αkcAk; (7) ReLU to keep only positive influence; (8) upsample to the image.
Grad-CAM works on many CNN families without changing the architecture: CNNs with FC layers (VGG), structured outputs (captioning), multi-modal inputs (VQA), reinforcement learning. A good visual explanation is (a) class-discriminative and (b) high-resolution.

6.7 CNN architectures: LeNet to ResNet

A CNN combines convolution layers, pooling layers, fully connected layers, normalisation (usually after conv/FC layers, before the nonlinearity) and activation functions. For each architecture ask: (1) its basic structure, (2) the problem it addressed, (3) are deeper/wider models always better?

The ImageNet competition ended in 2017; newer backbones include MobileNet, EfficientNet, ResNeXt, ConvNeXt and Transformer backbones.

6.8 Transfer learning with CNN backbones

Early-to-mid CNN layers encode low-level features (edges, textures, object parts) hierarchically, so a pre-trained backbone + new head is reused instead of training from scratch. Fine-tuning options, from cheapest to most flexible:

  1. Freeze the backbone, fine-tune the final fully connected layer.
  2. Freeze the backbone, fine-tune several FC layers.
  3. Fine-tune both the backbone and the FC layers.

Pre-trained backbones also feed other downstream tasks — U-Net segmentation, image captioning (CNN + RNN), detection.
