3.1 Effect of the activation function

Sigmoid σ(v) = 1/(1 + e−v)

Disadvantages:

  • Not zero-centred — output range (0, 1), always positive.
  • Weak gradient: σ′ = σ(1 − σ) ≤ 0.25.
  • Vanishing gradients — in the flat tails Δw is very small (saturation).

tanh(v)

Advantages: zero-centred output (−1, 1) → weights can move in both directions → faster convergence; stronger gradient (slope 1 at 0).

Disadvantages: still saturates — vanishing gradients for large |v|, though less severe than sigmoid.

Derivative: tanh′(v) = 1 − tanh²(v).

Linear neuron, x1 = 1, x2 = 2, w1 = w2 = 0.5, b = 0, target d = 0, η = 0.1.
Forward: z = 0.5·1 + 0.5·2 = 1.5 = y; E = ½(0 − 1.5)² = 1.125. Shared term ∂L/∂y·∂y/∂z = −(d − y)·1 = 1.5.
∂L/∂w1 = 1.5 × 1 = +1.5, ∂L/∂w2 = 1.5 × 2 = +3.0 → w1 = 0.5 − 0.15 = 0.35, w2 = 0.5 − 0.3 = 0.20.
Because both inputs are positive, both gradients always have the same sign: the weights can only move together (+/+ or −/−). If the optimum is (0.8, 0.1) — w1 up, w2 down — the optimiser must zig-zag. Sigmoid outputs feeding the next layer are always positive, so the next layer has exactly this problem.

3.2 Properties of backpropagation

  • Backpropagation provides an approximation to the trajectory in weight space computed by the method of steepest descent.
  • Gradient descent over all network weights; easily generalised to arbitrary architectures.
  • Finds a local minimum — not always global — but in practice often works well.
  • Minimises error over the training examples; training can take thousands of iterations (slow), but inference is fast.

3.3 The learning rate

Learning rateBehaviour
HighLarge weight changes, faster initial progress, but can overshoot the minimum, oscillate (unstable) or diverge. A loss curve that jumps around or rises → η too high.
LowSmooth, stable trajectory but very slow; can stall on plateaus or in local minima. High error after 50 iterations at η = 0.0001 → it simply hasn't arrived yet.
ModerateGood balance of speed and stability.

The step taken is Δw = −η ∇E: its length is the product of the learning rate and the gradient (the arrows in the "ball rolling down a curve" picture). The gradient alone fixes the direction; η only scales it.

  • Give every adjustable weight its own learning rate.
  • Let each learning rate change from one iteration to the next.
  • If the derivative of the cost w.r.t. a weight keeps the same sign for several iterations → increase that learning rate.
  • If it alternates in sign → decrease it.

3.4 Momentum

A simple way to increase the rate of learning while avoiding instability: add a fraction α of the previous update (Haykin's generalised delta rule):
Δw(n) = α Δw(n − 1) − η ∂E/∂w(n), 0 ≤ α < 1 (the momentum constant).
Assignment forms: ΔW(n) = g(n) + αΔW(n − 1), or vt = βvt−1 + ∇J(θt), θt+1 = θt − ηvt.
Unrolling the recurrence: Δw(n) = Σj=0n αn−j g(j) — the current gradient has weight α0 = 1 (100 %), the previous one α (90 % if α = 0.9), two steps ago α² (81 %)… older gradients decay exponentially. E.g. ΔW(3) = g(3) + αg(2) + α²g(1).
Dampens oscillations: if gradients keep flipping sign (zig-zag), the terms cancel and smooth the path. Accelerates on plateaus: if gradients point the same way, the sum grows (a ball picking up speed) — effective step up to η/(1 − α) for a constant gradient. Uses information from previous gradients.
α close to 1 (e.g. 0.99) keeps past gradients alive for a long time → the updates can overshoot the minimum. Momentum does not guarantee the global minimum on non-convex surfaces.

vt−1 = 2, β = 0.9, ∇J = 3, η = 0.1, θt = 5: vt = 0.9 × 2 + 3 = 4.8 → θt+1 = 5 − 0.1 × 4.8 = 4.52.

3.6 Curve fitting, overfitting and regularisation

Bishop's example: predict t from x; the unknown truth is sin(2πx) plus random noise; N = 10 points evenly spaced in [0, 1]. Model: y(x, w) = Σj=0M wjxj — nonlinear in x but linear in w. Error: E(w) = ½Σ{y(xn, w) − tn}² (half the sum of squared vertical distances).
  • M = 0, 1: poor fit — underfitting; fails to capture sin(2πx).
  • M = 3: good fit of the underlying trend.
  • M = 9: 10 coefficients for 10 points → passes exactly through every point, E(w*) = 0, but oscillates wildly between points, especially near the ends; test error rises → overfitting (fitting the noise). The coefficients become huge, with large positive and negative values.
  • More data (N = 15 → 100) reduces overfitting for a fixed M. Heuristic: number of data points ≈ 5–10 × number of parameters.
Regularisation: Ẽ(w) = ½Σ{y(xn, w) − tn}² + (λ/2)‖w‖². With M = 9: λ = 0 → oscillating overfit; moderate ln λ = −18 → smooth curve close to sin(2πx), smaller coefficients; large ln λ = 0 → over-regularised, flattened, underfit. Choose M or λ on a validation (hold-out) set, not on the training set.
Training error alone always prefers the most complex model — the goal is generalisation.

Ways to control capacity (cs231n)

  • Loss-based regularisation — add a penalty to the error: L2 λΣw² (weight decay, small spread-out weights), L1 λΣ|w| (sparse weights), L1 + L2 (elastic net), L0 (count of non-zero weights).
  • Max-norm constraints — clamp every neuron's weight vector so ‖w‖2 < c (c typically 3 or 4). The network cannot "explode" even with a too-high learning rate, because updates stay bounded.
  • Dropout (Srivastava et al., 2014) — during training keep each neuron active with probability p, otherwise set it to zero; no dropout at test time.

3.7 Generalisation, cross-validation and early stopping

Learning is a "curve-fitting" problem; generalisation is the interpolation the network performs between training points. Learning too many input–output examples can make the network memorise — a look-up table with a non-smooth mapping: overfitting / overtraining.
Generalisation depends on three factors: (1) the size of the training sample and how representative it is of the environment, (2) the network architecture, (3) the physical complexity of the problem. Too few hidden units → underfitting; too many → overfitting (like fitting a quadratic with a degree ≫ 2 polynomial).
Remedies: avoidance — hold-out cross-validation (decides when to stop), weight decay (shrink each weight a little every epoch); detection/recovery — random restarts, adding/deleting weights or units.
MethodHowTrade-off
Hold-outSplit into training (estimation) and validation setsSimple; estimate depends on the split
K-fold (multifold) CVK equal folds; train on K − 1, validate on the remaining one; repeat K times so each fold validates once; report the average validation errorMore reliable estimate; K times the training cost
Early stoppingTrain for a period, pause, check validation error, resume. Training error falls monotonically; validation error falls, reaches a minimum, then rises (overfitting) → stop at the minimumNeeds a validation set; cheap and effective

3.8 Loss functions for neural classifiers

Formulation: samples (xi, yi), x m-dimensional, y an n-dimensional coded class label (target +1 for the true class, −1 for the others). Predicted class = argmaxj yij. The network approximates the decision surface: y = f(W, x) + εa + εe.
Approximation error εa — model bias: the chosen architecture cannot represent the true decision boundary even with unlimited data (limited capacity → increase capacity).
Estimation error εe — variance: the architecture is powerful enough but the best parameters can't be learned (finite, noisy or imbalanced samples, overfitting, optimisation → early stopping, regularisation, more data).
Risk bound: RN ≥ lB + εa + εe (lB = optimal Bayes error).
Loss (d ∈ {−1, +1})FormulaProperties from the lecture
Least squares (LS)Σ(y − d)²Sigmoid outputs saturate; sensitive to labels, finite data and imbalance; may overfit; not guaranteed to reach the optimal Bayes classifier. Penalises "too correct" outputs (y = 2.5 for d = 1 gives loss 2.25).
Modified LS (MLS)Σ max(0, 1 − yd)²Zero once yd ≥ 1 → no penalty for being "too correct" (zero-loss plateau beyond the margin). Uses sub-gradients (more computation); linear output layer with truncated output; better posterior estimates; not sensitive to labels but sensitive to class overlap, finite data, imbalance.
Fourth power (FPE)Σ(y − d)⁴Penalises misclassification strongly, but for small errors the gradient (∝ e³) is tiny → vanishing gradient near convergence; poor posterior estimates; gradient stability issues.
Binary / categorical cross-entropyΣ [(1 + d)/2]·log[(1 + d)/(1 + y)] + [(1 − d)/2]·log[(1 − d)/(1 − y)]Consistent towards the optimal Bayes classifier; slow convergence; better posteriors than MLS; handles some class overlap. With a sigmoid output its gradient is (y − d) — σ′ cancels, so it does not stall when confidently wrong.
Focal loss−(1/N) Σ ((1 − y)/2)γ log((1 + y)/2)The modulating factor ((1 − y)/2)γ down-weights easy examples (e.g. 99.9 % background); handles class overlap and imbalance effectively; consistent towards Bayes; more sensitive to noisy labels than CCE. γ = 0 → cross-entropy.
Risk-sensitive hingehinge-type loss with an adaptive risk term (Suresh et al., 2008)Consistent towards Bayes; zero loss beyond the margin; not sensitive to labels; handles overlap better than focal; not sensitive to finite data or imbalance; adaptive risk helps convergence; slow and computation-heavy.

On a well-balanced satellite dataset all losses do reasonably; when imbalance is artificially introduced in class 2, the risk-sensitive loss holds up best — risk estimation handles sample imbalance and acts differently in different regions of the error surface.
