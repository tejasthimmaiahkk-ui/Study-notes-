9.1 The segmentation task

Semantic segmentation = assign a class label to every pixel — classification, but per pixel (a huge increase in decision space). Training needs every pixel annotated — annotation-intensive. Labels: an n-channel one-hot mask or a single-channel index mask.
Precise areas and better localisation ("which car is closer?"), scene understanding. Drone example: SpaceNet 6 building detection — buildings, building boundaries and the tiny gaps between buildings. Benchmark: ADE20K (~25,000 images: 20,210 train / 2,000 val / 3,352 test).
Design options: (1) sliding window — classify the centre pixel of every patch: impractical; (2) a fully convolutional network without downsampling — output matches input but too expensive; (3) encoder–decoder: the encoder downsamples (cheap, large receptive field), the decoder upsamples back; predict C × H × W scores, then argmax per pixel → H × W label map. Losses: cross-entropy, Dice, focal.

9.2 Upsampling operations

  • Max unpooling (reverse max-pooling): remember where each maximum came from; put the value back there, zeros elsewhere — preserves the structure of the stimulus.
  • Nearest-neighbour unpooling: copy each value into its whole block — ignores which neuron fired.
  • Transposed convolution: multiply by the transpose of the convolution matrix — each input value stamps a learned kernel onto a larger output. Output = (H − 1)·S − 2P + K (+ output padding). k = 2, s = 2 doubles the size: 5 × 5 → 10 × 10.

9.3 Fully Convolutional Network (Long, Shelhamer & Darrell, 2015)

Take a classification network (AlexNet, VGG, GoogLeNet) and replace its fully connected layers by convolutions — an FC layer is a convolution whose kernel covers its whole input. The network accepts any input size and outputs a spatial heat map instead of one label — preserving spatial information for a prediction at every pixel.
A 1 × 1 conv with 21 channels predicts class scores (20 PASCAL classes + background); a deconvolution layer (initialised as bilinear upsampling) produces pixel-dense outputs. FCN-32s upsamples the stride-32 prediction in one step (deep semantics only); FCN-16s also fuses pool4 predictions, FCN-8s adds pool3 — combining coarse semantic information with fine appearance information through skip connections. Loss: pixel-wise multinomial logistic (softmax cross-entropy) summed over all pixels.

9.4 Evaluation: IoU, mIoU and mAP

Per class c (pixel counts): IoUc = TPc / (TPc + FPc + FNc); mIoU = (1/C) Σc IoUc. From a confusion matrix (rows = truth, columns = prediction): TP = diagonal, FP = column sum − TP, FN = row sum − TP.
Instance segmentation / detection: a prediction matches if IoU > threshold (commonly 0.5) and the class is right; precision = TP/(TP + FP), recall = TP/(TP + FN); AP = area under the precision–recall curve; mAP = mean over classes; COCO additionally averages over 10 IoU thresholds 0.5 : 0.05 : 0.95.

9.5 SegNet and U-Net

SegNet

Encoder = the 13 conv layers of VGG-16 (initialised from classification weights); decoder maps low-resolution encoder features back to full resolution; then a pixel-wise classifier. The decoder upsamples with max-unpooling using the encoder's stored pooling indices (non-linear upsampling that preserves the locations of the strongest activations); the sparse maps are then convolved with trainable filters into dense maps. Only indices are stored → memory-efficient. Loss: pixel-wise softmax cross-entropy.

U-Net (Ronneberger et al., 2015)

Proposed for medical images; U-shaped. Encoder (contracting) increases the field of view; decoder (expanding) upsamples to high resolution; skip connections concatenate encoder features with the decoder features at the same resolution → better-localised segmentation (fine spatial detail + deep semantics). Loss: pixel-wise softmax + weighted cross-entropy, w(x) = wc(x) + w0·exp(−(d1(x) + d2(x))²/(2σ²)) — class-balancing plus extra weight on pixels between touching objects (d1, d2 = distances to the nearest and second-nearest cell border).

Rough object presence survives in the bottleneck, but precise boundaries don't: downsampling irreversibly throws away spatial detail, hurting small objects (a few pixels) most. Skip connections restore it.

9.6 Multi-scale context: image pyramids, SPP and PSPNet

  • Image pyramids: run the model on several scaled copies — small-scale inputs encode long-range context; large-scale inputs keep small-object detail.
  • Encoder–decoder: the encoder captures long-range information by reducing resolution; the decoder recovers object details (boundaries).
  • Spatial Pyramid Pooling: probe the feature map with pooling at several bin sizes / fields of view. Bins = Σ n² over levels: levels 1 × 1, 2 × 2, 4 × 4 give 21 bins → 21 × 256 = 5,376 values, fixed regardless of input size.
  • PSPNet (Pyramid Scene Parsing): pre-trained ResNet encoder; pyramid pooling module with 4 levels — from global pooling (1 bin, whole image) to half and smaller portions; the pooled maps are upsampled bilinearly and concatenated with the original features, then a conv gives the prediction. Deep supervision: L = Lmain + α·Laux (an auxiliary cross-entropy loss branched from an intermediate ResNet layer).

9.7 DeepLabv3 and DeepLabv3+

Problem with classification backbones for segmentation: deeper layers lose "where in the image?" (resolution drops) while their receptive field grows — good for large objects, bad for small ones.
Atrous (dilated) convolution: y[i] = Σk x[i + r·k]·w[k] — insert holes between filter weights (rate r). Controls resolution and enlarges the field of view without extra parameters or computation, giving dense features from ImageNet backbones (strides/pooling in later blocks are replaced by dilation).
ASPP (Atrous Spatial Pyramid Pooling): parallel atrous convolutions with different rates — probing the image with complementary fields of view to capture objects and context at multiple scales without reducing resolution. DeepLabv3's ASPP has five branches (1 × 1 conv, three 3 × 3 atrous convs, image-level pooling), concatenated → 1 × 1 conv to mix → final 1 × 1 conv → bilinear upsampling. Loss: cross-entropy.
DeepLabv3+ = DeepLabv3 as the encoder + a simple decoder to refine boundaries: take low-level features from a shallow backbone layer, reduce their channels with a 1 × 1 conv; upsample the encoder output ×4; concatenate; two 3 × 3 convs; upsample ×4. Backbone Xception (or ResNet). Uses atrous separable convolution = depthwise convolution (per channel, dilated) + pointwise (1 × 1) convolution to combine channels.
DeepLabv3 (SPP/ASPP: multi-scale context) + U-Net-style decoder (recover spatial detail) = the best of both worlds.

9.8 Undercomplete vs overcomplete networks (KiU-Net, DeepMAO)

Undercomplete autoencoder: latent dimension smaller than the input (dim z < dim x) — forced to compress, it learns the most salient structure. U-Net is undercomplete: going deeper, spatial resolution falls and the receptive field grows. Even with skip connections, U-Net fails on small structures and blurred/noisy boundaries, because deep layers focus on high-level features.
With pooling and stride 2 (undercomplete), block 2 sees 2k × 2k of the input and block 3 sees 4k × 4k: RF = 22(i−1) × k × k. Overcomplete networks project the input into a higher spatial dimension (bilinear upsampling in the encoder) so the receptive field shrinks: ½k × ½k, then ¼k × ¼k: RF = (½)2(i−1) × k × k — the two are reciprocals.
KiU-Net (Valanarasu et al., 2021): an overcomplete branch (Kite-Net, fine details and boundaries even in deep layers) + an undercomplete branch (U-Net), fused at several scales by cross residual feature blocks (CRFB); binary cross-entropy loss.
DeepMAO (Deep Multi-scale Aware Overcomplete network): U-Net branch + overcomplete branch for building segmentation (SpaceNet 6) and land-cover (OpenEarthMap). Grad-CAM shows the overcomplete branch focuses on smaller features — edges and fine-grained structure, the undercomplete branch on larger features and intricate building shapes. Loss: Dice + focal.

9.9 Per-pixel vs mask classification: MaskFormer

Per-pixel classification (FCN and successors) predicts a distribution over K classes for every pixel and applies the same loss everywhere — it couples "partitioning" and "classification" into one dense decision. Mask classification disentangles them: predict a set of N binary masks (partitioning; N need not equal K), each with one class distribution over K classes plus a "no object" label ∅. Predictions are matched to ground-truth segments (a matching σ).
MaskFormer (Cheng, Schwing & Kirillov, 2021) computes N probability–mask pairs with three modules: (1) pixel-level module — backbone → low-resolution features F → pixel decoder → per-pixel embeddings; (2) transformer module — a Transformer decoder turns F and N learnable queries into per-segment embeddings Q (all predictions in parallel); (3) segmentation module — a linear classifier + softmax on Q gives class probabilities (with ∅); an MLP turns Q into mask embeddings; each mask = sigmoid(dot product of its mask embedding with the per-pixel embeddings). Loss: cross-entropy classification + binary mask loss (focal + Dice).
Because semantic and instance segmentation both reduce to predicting class-labelled masks — one mask per class for semantic, one per object for instance — the same N-pair format covers both.

SAM (Segment Anything v1) learns a general notion of objectness / segmentability. Task: promptable segmentation — given a prompt (foreground/background points, a box, a mask, or free-form text) output a valid mask, even when the prompt is ambiguous. It can also segment everything automatically.
SA-1B: 1.1 billion class-agnostic masks from 11 million diverse images (natural, urban, medical, satellite…). Data engine in three stages: (1) model-assisted manual annotation (annotators click points in a SAM-powered tool; the model is retrained as it improves); (2) semi-automatic (SAM proposes masks for likely objects, annotators add the rest → more diversity); (3) fully automatic (a regular grid of point prompts, ~100 high-quality masks per image).
Architecture: image encoder — a ViT pre-trained with MAE, run once per image; prompt encoder — sparse prompts (points, boxes → positional encodings + learned type embeddings; text → CLIP text encoder) and dense prompts (masks → convolutions, summed with the image embedding); lightweight mask decoder — Transformer-style blocks with prompt self-attention and cross-attention, then a dynamic mask head. For ambiguous prompts it outputs several masks (typically 3: whole, part, subpart) with confidence scores — averaging them would blend different valid objects into one incoherent region.
Fine-tuning usually touches only the mask decoder — light, fast and memory-efficient.

9.11 Instance and panoptic segmentation, Mask R-CNN

Detection gives boxes but no pixel-level understanding; semantic segmentation labels pixels but does not separate objects of the same class. Instance segmentation recognises and classifies each object and gives a precise pixel mask per object. Panoptic segmentation unifies semantic segmentation (every pixel, including "stuff" like road and sky) and instance segmentation ("things" like individual cars).
Mask R-CNN = Faster R-CNN + a mask branch: backbone → feature map → RPN → RoI features via RoI Align → R-CNN head (class + box) and a small FCN head (mask). Multi-task loss = classification + localisation + mask.
RoI Pooling vs RoI Align: with a feature map downsampled k times, RoI Pooling takes ⌊x/k⌋ (integer part) and quantises the bins; RoI Align divides by k without rounding, samples 4 points per bin by bilinear interpolation of the 4 neighbouring cells (e.g. S1·P(3,3) + S2·P(3,2) + S3·P(2,3) + S4·P(2,2)), then max/average-pools them — every value comes from sub-pixel-accurate coordinates, so masks stay aligned with the object.

9.12 Domain generalisation and aerial perception

Standard evaluation assumes training and test data are i.i.d. — from the same distribution. Domain generalisation: learn h : X → Y from M source domains (each with a different joint distribution) so that the error is minimal on an unseen target domain.
Types of distribution shift: covariate shift — the feature distribution P(x) changes, the label distribution does not; label shift — the label distribution P(y) changes between train and test; concept shift — the mechanism linking features to labels P(y | x) changes.
Evidence: DeepLabv3+ (ResNet-50) trained on sunny Cityscapes drops sharply on BDD100K, Mapillary, GTAV, Synthia and on night images; static training data cannot cover changing test conditions (geography, weather, illumination, sensor).
Aerial specifics: sim-to-real gaps; sensor gaps (RGB ↔ IR); SAR works in all weather and light but is complex-valued with speckle noise, while optical (EO)/hyperspectral cannot work in all light; the missing-modality problem (EO, IR, SAR available in training but only SAR at inference — SpaceNet 6 MSAW); the IndraEye drone dataset (EO + IR, not co-registered, high altitude, varying slant angles). Off-nadir views shrink distant objects and performance drops for moderate-to-extreme off-nadir angles; domain shift comes from view angle, sensor and illumination.
