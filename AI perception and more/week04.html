4.1 Tensors: rank, shape and size

A tensor is an n-dimensional array. Its rank (also called order or ndim) is the number of axes = the number of indices you need to pick out one value. Its shape lists the length of each axis; its size is the product of the shape (total number of elements).

  • The matrix [[1, 2], [3, 4], [5, 6]] has shape (3, 2), size 6 and rank 2: the value 5 is at row 2, column 0 — two indices. Rank is not the number of elements, rows or unique values.
  • Reshape changes the shape but keeps the size (6 × 20 = 120 = 3 × 2 × 4 × 5). Transpose/permute reorders axes: (3, 2, 4, 5) → (5, 2, 4, 3) is still rank 4 with 120 elements.
  • Broadcasting: shapes (3, 1) and (1, 4) combine to (3, 4) — size-1 axes stretch.
Tensor rank ≠ matrix rank. The matrix rank of [[1, 2], [3, 4], [5, 6]] is also 2 here (two independent columns), but a 3 × 3 all-ones matrix has tensor rank 2 and matrix rank 1.

4.2 Least squares

Fit a model ŷ = f(x, w) by minimising the sum of squared errors SSE = Σ(yi − ŷi)² (or its mean, the MSE). This is the error function of the delta/LMS rule (Week 2) and of curve fitting (Week 3).
Why square?
  1. No cancellation: errors (+8, −8, +8, −8) have raw sum 0 — a "perfect fit" that is wrong by 8 everywhere — but SSE = 4 × 64 = 256.
  2. Large errors cost much more: errors (+1, +1, +1, +1) give SSE 4; (+10, −10, +1, −1) give 202. Least squares prefers small consistent errors to a few large ones.
  3. Smooth and differentiable → gradient descent works, and for models linear in w there is a closed-form solution.
Straight line ŷ = mx + c: m = Σ(x − x̄)(y − ȳ)/Σ(x − x̄)², c = ȳ − m x̄.
Matrix form (any model linear in w, design matrix Φ): minimise ‖t − Φw‖² → normal equations ΦᵀΦw = Φᵀt → w = (ΦᵀΦ)⁻¹Φᵀt = Φ⁺t (pseudo-inverse). With L2 regularisation: (ΦᵀΦ + λI)w = Φᵀt.
Line and polynomial fitting, linear regression, the output layer of an RBF network, calibration of sensors.
Because errors are squared, a single outlier can pull the fit strongly. Absolute error (Σ|e|) or robust losses (e.g. Huber/smooth L1, Week 8) are less sensitive. Mean error alone is useless as a fit measure — with an intercept, the LS residuals always sum to 0.

4.3 Cover's theorem — why a nonlinear hidden layer helps

Cover's theorem (1965): a complex pattern-classification problem cast nonlinearly into a high-dimensional space is more likely to be linearly separable than in a low-dimensional space.
This is the idea behind RBF networks: a hidden layer of nonlinear units φk(x) maps each input to a new feature vector; a linear output layer then only has to draw a hyperplane.
XOR example (Haykin): φ1(x) = exp(−‖x − t1‖²), φ2(x) = exp(−‖x − t2‖²) with t1 = (1, 1), t2 = (0, 0). The inputs (0, 1) and (1, 0) both map to (0.368, 0.368); (1, 1) → (1, 0.135) and (0, 0) → (0.135, 1). XOR becomes linearly separable — even without increasing the dimension.

4.4 Radial basis functions and RBF networks

A radial basis function depends only on the distance between the input and a centre: φ(x) = φ(‖x − c‖). Common choices (r = ‖x − c‖):
  • Gaussian φ(r) = exp(−r²/(2σ²)) — 1 at the centre, decreasing with distance; σ sets the width (most common).
  • Multiquadric φ(r) = √(r² + c²) — increases with distance.
  • Inverse multiquadric φ(r) = 1/√(r² + c²) — decreases with distance.
So "the output always increases with distance" is false in general.
RBF network (three layers):
  1. Input layer — passes x on (no weights).
  2. Hidden layer — K radial units, each with a centre ck and width σk: hk = φ(‖x − ck‖). Nonlinear, local response.
  3. Output layer — linear: y = w0 + Σk wkhk.
Training in two stages: (1) choose centres — fixed at random training points, or by k-means clustering — and widths (e.g. σ = dmax/√(2K), dmax = largest distance between centres); (2) solve the output weights by linear least squares (pseudo-inverse) or the LMS rule. Centres can also be fine-tuned by gradient descent (supervised selection).
Exact interpolation: put one centre on each of the N data points → the N × N interpolation matrix Φ (Φij = φ(‖xi − xj‖)) gives Φw = d. Micchelli's theorem: for distinct points and Gaussian/multiquadric φ, Φ is non-singular, so w = Φ⁻¹d exists. The surface passes through every point — and so also fits the noise.
Interpolation and function approximation (an RBF network is a universal approximator), time-series prediction, classification, control.
Needs many units in high dimensions (each unit only covers a local region — curse of dimensionality); the choice of centres and σ matters a lot: σ too small → spiky, poor generalisation; σ too large → over-smooth and ill-conditioned.
