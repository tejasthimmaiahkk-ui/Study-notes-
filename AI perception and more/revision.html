R.4 Exam traps: the wrong options the assignments keep using

  1. Precision vs recall swapped. Precision divides by predicted positives, recall by actual positives. High accuracy on imbalanced data can hide zero recall.
  2. "Epochs exceed the number of input features" is not a stopping criterion. Use a validation-error minimum, an error threshold, or no more weight change.
  3. A single-layer perceptron cannot learn XOR, at any learning rate or for any number of epochs.
  4. Activations exist to add nonlinearity. A stack of linear layers is still one linear map.
  5. Tensor rank is the number of axes, not the number of elements, rows or the matrix rank.
  6. Raw error sums cancel (+8 and −8 give 0); squared errors don't.
  7. η too high oscillates or diverges; η too low is slow but stable. A high error after 50 iterations at η = 0.0001 means "not there yet", not "diverged".
  8. Momentum does not guarantee the global minimum; α near 1 can overshoot.
  9. Pooling has no learnable parameters. Max-pooling is nonlinear; average pooling is linear.
  10. Transfer learning is not guaranteed to help: large domain gaps (RGB → SAR/IR, ground → aerial) cause negative transfer.
  11. ResNet's problem was degradation (optimisation), not overfitting; the shortcut adds no parameters.
  12. BN depends on the batch; LN/IN/GN don't, so they suit batch size 1 and RNNs.
  13. LSTM: the cell state is updated by addition, so gradients survive; the LSTM is still sequential. Attention removes the sequential bottleneck.
  14. RoI Pooling rounds; RoI Align interpolates (no quantisation). DETR needs no anchors and no NMS (Hungarian matching).
  15. YOLO v1 has one class set per cell, so two objects whose centres fall in the same cell clash.
  16. mIoU is the mean of per-class IoUs, not pixel accuracy. Dice = 2TP/(2TP + FP + FN) ≥ IoU.
  17. Atrous convolution enlarges the field of view with no extra parameters and without losing resolution.
  18. SAM outputs three masks (whole, part, subpart) for ambiguous prompts; fine-tune only the light mask decoder.
  19. Distillation temperature: a higher T softens outputs and exposes the similarity between classes; that is the reason, not "faster training". KL with the teacher first is mass-covering.
  20. SimCLR's projection head is discarded after pretraining; it absorbs the invariances the loss forces. MoCo = queue + momentum encoder, so negatives don't depend on batch size.
  21. "Prune the smallest γ, accuracy never changes" is false: it is a heuristic, and pruning too much hurts.
  22. "Freeze all weights to stop forgetting" is false: zero plasticity.
  23. Q-learning is off-policy (max); SARSA is on-policy (the actual a′); SARSA learns the safer cliff path.
  24. ε-greedy: P(greedy) is 1 − ε + ε/|A|, not 1 − ε.
  25. DQN's stabilisers are experience replay + a target network (not dropout or batch norm).
  26. GAN early training: D(G(z)) ≈ 0, so log(1 − D) saturates; use −log D. Mode collapse = sharp but low-diversity samples.
  27. WGAN's motivation: JSD is flat (log 2) when the distributions don't overlap, while the Wasserstein distance still gives gradients.
  28. Infeasible task cost = ∞ (κ), never zero or negative.
  29. Visual SLAM fails over sea or desert (no texture); LiDAR SLAM fails in featureless geometry (tunnels, open fields); scale ambiguity is a monocular-camera problem; radar is the all-weather option.
  30. Domain shift: covariate = P(x) changes; label = P(y) changes; concept = P(y | x) changes.
