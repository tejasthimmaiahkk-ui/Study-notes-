7.1 Sequential data

Sequential data: the order of elements carries meaning — reordering changes or destroys the information (speech, text, stock prices, sensor data, video). A time series X = {x1, …, xT} has temporal dependency: current values depend on earlier ones.
Characteristics: ordered observations, temporal correlations, dynamic evolution, variable sequence length. Components to understand: trend, seasonality (regular repeating patterns at fixed intervals), cyclic component (long-term fluctuations without fixed period).
Sequence-learning problems: inputs are not independent; input and output lengths may differ; the same task is performed at every step; the temporal context is variable. Video understanding: find the frame of interest, track across frames.

7.3 Memory Neuron Networks (Sastry, Santharam & Unnikrishnan, 1994)

Each network neuron (except those in the output layer) has a memory neuron whose single scalar output summarises the history of that neuron's past activations. A memory neuron takes its input from its network neuron and has a self-feedback. Output-layer neurons have a chain of memory neurons that feed back into their parent network neuron.
Network neuron: s(k) = g(x(k)). Memory neuron: v(k) = α·s(k − 1) + (1 − α)·v(k − 1) — α (memory coefficient) trades off the newest activation against the accumulated memory of all previous steps (an exponential moving average).
Hidden neuron: h(k) = g(Σ w·s(k) + Σ f·v(k)) — weights w from network neurons, f from memory neurons. Output neuron: h3(k) = g(Σ w·s + Σ f·v + β11v113(k) + β12v123(k)), with output memory neurons v113(k) = α11h3(k − 1) + (1 − α11)v113(k − 1) and v123(k) = α12v113(k − 1) + (1 − α12)v123(k − 1).
Learning (BPTT), error E(k) = ½(s(k) − y(k))², e(k) = (s(k) − y(k))·ĝ′:
  • Network weights: w(k + 1) = w(k) − η e(k) s(k); memory-to-network weights f and output weights β: β(k + 1) = β(k) − η e(k) v(k).
  • Memory coefficients: α11(k + 1) = α11(k) − η β11(k) v11(k) (h3(k − 1) − v11(k − 1)) — an extra difference term, because α controls a recurrent blend: its gradient must account for how the earlier memory value was itself shaped by α (∂v/∂α = s(k − 1) − v(k − 1)). β has no such dependency.
α is a single (learned) scalar shared across all time steps — the decay rate is content-blind, not input-dependent. LSTMs replace it with gates computed afresh from the input at every step.

7.4 Drone system identification and GPS-denied operation

System identification: learn the input–output dynamics of the drone, e.g. the yaw subsystem ṙ = fr(r, Ωd, Vd, Θd), from data (step response to a unit yaw-stick change). Temporal data is captured by unrolling the subsystem over time with a hidden state h: y = f(U, h).
Billings' theorem: a dynamical system's input–output model can be written yk+1 = f(yk, …, y0, uk, …, u0). Universal approximation theorem: a single-hidden-layer network with enough hidden neurons can approximate that nonlinear f, given the past k inputs and outputs (k = order of the system).
Procedure: generate data with persistently exciting inputs → train the MNN to approximate the relationship (error e(k) between drone and network output) → test and validate on new inputs.
GPS-denied operation (indoors, near buildings, under forest canopy, clutter): use the IMU to estimate change in velocity, attitude and position — but it drifts over time. Sensor suite: magnetometer (heading reference), barometer (altitude drift correction), optical flow (relative velocity at low altitude). Fusion with an Extended Kalman Filter (or Unscented KF for strong nonlinearity); map/terrain-aided navigation; SLAM (visual or LiDAR) — build a map of the unknown environment ("what does it look like?") and localise within it ("where am I?") simultaneously.

7.5 Recurrent neural networks

A "black box" with an internal state updated as the sequence is processed: ht = tanh(Whhht−1 + Wxhxt), yt = Whyht. Course notation: st = tanh(Uxt + Wst−1), ŷt = softmax(Vst). Recurrent because the same task, with the same parameters U, V, W, is performed for every element; the output depends on previous computations.
Why share parameters? The same learned transformation applies at every step, so the model handles sequences of any length with a fixed number of parameters, and a pattern learned at one position is recognised wherever it occurs. CNNs need fixed-size inputs and cannot do this.
Architectures: one-to-many (image captioning: one image → a sentence), many-to-one (video frames → action label; sentiment), many-to-many (video captioning, machine translation). Example: a character-level language model predicts the next character at every step.
Bidirectional RNNs: two RNNs, one reading forwards and one backwards; the output uses both hidden states (e.g. fill in a missing word using left and right context).
Long-term dependencies: as the gap between the relevant information and where it is needed grows, RNNs become unable to connect them.

7.6 Backpropagation through time and vanishing gradients

Find U, V, W minimising the total loss — cross-entropy over all steps: Et = −yt log ŷt, E = Σt Et. Unroll the network in time and backpropagate; learn with SGD.
Output weights: ∂E3/∂V = (ŷ3 − y3) ⊗ s3 — depends only on the current step.
Recurrent weights: because W is shared, s3 depends on W through s2, s1, …:
∂E3/∂W = Σk=03 (∂E3/∂ŷ3)(∂ŷ3/∂s3)(∂s3/∂sk)(∂sk/∂W) — every earlier hidden state that fed into s3 contributes, so the contributions are summed.
∂s3/∂sk is a product of Jacobians W·tanh′(·). tanh′ ≤ 1 (and tiny when saturated), so the product vanishes for distant steps → long-range dependencies are not learned. Large weights make it explode (fix: gradient clipping).

7.7 Long Short-Term Memory (LSTM)

Designed to avoid the long-term dependency problem — remembering information for long periods is practically its default behaviour. The repeating module has four interacting layers instead of one tanh.
Cell state Ct: the horizontal line through the top of the diagram; information flows along it almost unchanged, modified only through gates (a sigmoid layer + point-wise multiplication).
  1. Forget gate: ft = σ(Wf·[ht−1, xt] + bf) — what to throw away from Ct−1.
  2. Input gate: it = σ(Wi·[ht−1, xt] + bi) and candidate C̃t = tanh(WC·[ht−1, xt] + bC) — what new information to store.
  3. Update: Ct = ft ⊙ Ct−1 + it ⊙ C̃t.
  4. Output gate: ot = σ(Wo·[ht−1, xt] + bo); ht = ot ⊙ tanh(Ct) — a filtered version of the cell state.
Why the cell state preserves information: it is updated by addition (identity-like), not squashed through tanh at every step, so with f ≈ 1 the gradient ∂Ct/∂Ct−1 ≈ 1. Why two gates: "retain" and "add" are independent decisions — sometimes you must keep the old memory and write new information.
Still sequential (no parallelism across time). Variants: peephole connections (gates also look at the cell state; Gers & Schmidhuber, 2000); GRU (Cho et al., 2014) merges forget and input gates into one update gate and the cell into the hidden state.

7.8 Attention (Bahdanau et al., 2015)

In a vanilla encoder–decoder, the encoder's last hidden state is a single fixed-length context vector used at every decoding step — no weights for other inputs. This is an information bottleneck that worsens with source length.
Attention = a vector of importance weights. It creates shortcuts between the context vector and the entire source input, with weights customised for each output element:
encoder = bidirectional RNN with states h1 … hn; for output position t, an alignment model (a small feed-forward network) scores how well input i matches output t: score(st−1, hi); αt,i = softmax over i; context ct = Σi αt,ihi, recomputed at every decoder step; decoder st = f(st−1, yt−1, ct).
Alignment score functions: additive/content-based (Bahdanau) vTtanh(W[s; h]), dot-product sTh, general sTWh, scaled dot-product sTh/√n (Transformer).
The context vector relates encoder states, decoder states and the source–target alignment, which is learned; it can be visualised as an alignment matrix.

7.9 Self-attention and the Transformer

In "The animal didn't cross the street because it was too tired", self-attention lets "it" attend strongly to "animal" — each word attends to every word of the same sentence.
  1. From each input vector create a query, key and value vector (multiply by learned WQ, WK, WV).
  2. Score = q · k for every word.
  3. Divide by √dk (= 8 for dk = 64) → more stable gradients.
  4. Softmax → weights all positive, less than 1, summing to 1.
  5. Multiply each value vector by its weight and sum — keeps the words to focus on, drowns out irrelevant ones.
In matrix form: Attention(Q, K, V) = softmax(QKT/√dk)V.
Multi-head attention: several Q/K/V weight sets → several "representation subspaces"; heads are concatenated and projected. Positional encoding adds word order (attention itself is order-agnostic). The Transformer stacks encoder blocks (self-attention + feed-forward) and decoder blocks (masked self-attention + encoder–decoder attention + FFN).
Whole sequence processed in parallel; any position reaches any other in one step. Vision use: DETR — a transformer decoder takes encoded image features plus a set of learned object queries (Week 8).
