Biological neuron (the pyramidal cell)

Dendrites receive inputs from other neurons; the axon transmits the output; a synapse is where the axon of the presynaptic (source) neuron meets the dendrites of the postsynaptic (target) neuron; neurotransmitters are the chemical messengers across the synapse, either excitatory or inhibitory.
Artificial mapping: inputs xj ↔ signals on dendrites; weights wj ↔ synaptic strengths (positive = excitatory, negative = inhibitory); summation and activation ↔ the cell body deciding whether to fire; output y ↔ axon.

2.2 The single-neuron model and the bias

v = Σj=1m wjxj + w0x0 = wTx with the augmented vectors x = [x0, x1, …, xm], w = [w0, w1, …, wm]; output y = g(v).
The course uses a bias input x0 = −1 (so w0 acts as a threshold) and writes w0 first in the weight vector.

Why a learnable bias?

Without a bias, v = 0 whenever all inputs are 0, and every decision boundary must pass through the origin.
  • Gives a non-zero output when the inputs are zero.
  • Controls the decision boundary — most real data is not centred at zero.
  • Acts like a threshold on the strength of the input signal.
  • Shifts the activation function, i.e. adds an offset to the decision boundary.
  • Weights control the orientation (tilt) of the hyperplane; the bias controls its position (shift).

Output 1 when Σwjxj + w0(−1) > 0, i.e. wTx > w0, i.e. ‖w‖‖x‖cos θ > w0. The projection of x on w must exceed d = w0/‖w‖ — the distance of the boundary from the origin. Changing w tilts the line; changing w0 slides it.

The purpose of activation functions is to introduce nonlinearity. Linear activations produce linear decisions no matter how large the network is (W2W1x is still one matrix times x). Nonlinearities let the network approximate arbitrarily complex functions. Continuous activations also allow gradient computation for learning.

2.4 Hebbian learning

"When an axon of cell A is near enough to excite a cell B and repeatedly or persistently takes part in firing it, some growth process or metabolic change takes place in one or both cells such that A's efficiency, as one of the cells firing B, is increased." — "Neurons that fire together, wire together."

Update: Δw = η y x (vectorised for a layer: ΔW = η y xT). Positive correlation (both sides active together) strengthens the synapse; asynchronous activity weakens it.
Self-organising feature learning; models of biological plasticity.
It uses only the input x and the neuron's own output y — never the target d. So it is unsupervised, even if labels exist in the dataset: it strengthens connections whenever the neuron fires, even if that firing is "wrong".
With constant x and y the weight grows by ηxy every step — without bound (x = y = 1, η = 0.2 → w = 2 after 10 steps). Practical versions add normalisation or decay (e.g. Oja's rule — beyond the syllabus).

2.5 The perceptron, Boolean gates and linear separability

A perceptron is a neuron with a hard-limiting activation. With a unipolar step and inputs in {0, 1} it can implement logic gates:

GateTruth table (00, 01, 10, 11)Weights that work
AND0 0 0 1w1 = w2 = 1, bias −1.5 → x1 + x2 − 1.5
OR0 1 1 1w1 = w2 = 1, bias −0.5
NOT (1 input)1 0w1 = −1, bias +0.5 → 0.5 − x
NAND1 1 1 0 (complement of AND)w1 = w2 = −1, bias +1.5
XOR0 1 1 0 (1 when inputs differ)None — not linearly separable

A dataset is linearly separable if a straight line (a hyperplane in higher dimensions) separates the classes without any misclassification. AND, OR, NOT (and NAND, NOR) are separable; XOR is not — its 1s lie on one diagonal and its 0s on the other. A single-layer perceptron can only learn linearly separable functions.

Multi-class classification with perceptrons

Use one perceptron per class: perceptron k outputs 1 if the pattern belongs to class k, otherwise −1 (one-vs-rest). This works when each class is linearly separable from the rest.

2.6 Perceptron learning rule (delta rule)

Goal: find a boundary with wTx > 0 for class 1 and ≤ 0 for class 2. Correct classification → no change. Misclassified class-1 sample → w ← w + ηx; misclassified class-2 sample → w ← w − ηx. Both cases in one formula:

w ← w + η e x, e = d − y   (i.e. Δwi = η(d − y)xi)

With bipolar outputs e is 0 or ±2, so a mistake moves w by ±2ηx.
Convergence theorem: if the training data is linearly separable (and η is small enough), the rule finds a separating boundary in a finite number of steps; mistakes become rarer, so updates become progressively smaller and stop. On non-separable data (XOR) it never converges.
The hard limiter has no useful derivative (0 everywhere, undefined at 0), so the rule simply omits g′(v) — this is the correct way to train a hard-limiting neuron (assignment Q15).

2.7 Gradient descent for a continuous neuron

For a differentiable activation, define the squared error over the training set D: E(w) = ½ Σd∈D (d − y)². Find w* that minimises E by repeatedly stepping opposite to the gradient: w(new) = w(old) − η∇E(w).
Chain rule for one sample, y = g(v), v = wTx:
∂E/∂wi = (∂E/∂y)(∂y/∂v)(∂v/∂wi) = −(d − y) · g′(v) · xi
so the update is Δwi = −η ∂E/∂wi = η (d − y) g′(v) xi. The term (d − y)g′(v) is the local gradient δ: it gives the direction and size of the correction, and η scales the step. For a linear neuron (g′ = 1) this is the Widrow–Hoff delta / LMS rule: Δwi = η(t − y)xi with ∂E/∂wi = −(t − y)xi.
Gradient descent finds a local minimum of the error surface, not necessarily the global one. The weights start random; each step goes "downhill".

The slides write the gradient-descent update as Δw = −η(d − y)g′(v)x (and the assignment's comparison table repeats it), and the worked example uses that sign. Check: after the slide's second update, sample 2's net input drops from −1.24 to −3.09 although its target is +1 — the error grew. The error-reducing update is Δw = −η∂E/∂w = +η(d − y)g′(v)x; with it, sample 2's net input rises to +0.58. In MCQs, recognise "Δw = −η(d − y)g′(v)x" as the course's label for the gradient-descent rule; when computing, use the direction that reduces the error. The stepper above uses the correct sign.

2.8 Multi-layer perceptron and backpropagation

An MLP with architecture m : l : n (inputs : hidden neurons : outputs). Forward pass: hidden net input vi = Σ wij(1)xj (w1i = weight from input i to hidden neuron 1), hidden output hi = φ(vi), output yk = Σ wki(2)hi (linear or nonlinear output). Error ek = dk − yk, loss E = ½Σek².
Backpropagation = the chain rule applied layer by layer, from the output backwards.
  • Output local gradient: δk(2) = ek g′(vk); update Δwki(2) = η δk(2) hi.
  • Hidden local gradient: δi(1) = φ′(vi(1)) · Σk wki(2) δk(2) — its own slope times the output deltas, each weighted by the weight that carries hidden neuron i's signal to output k; update Δwij(1) = η δi(1) xj.
  • Case A (one output) has a single term; Case B (n outputs) sums over all outputs, because hidden neuron i affects every output.
For the chain x → φ → y → E: ∂E/∂w1 = (∂E/∂y)(∂y/∂v1)(∂v1/∂w1) — output-to-error, hidden-to-output, input-to-hidden. The chain rule is needed because w1 only directly influences v1; its effect on E travels through every later step.
Gradient descent over the whole weight vector finds a local minimum, not necessarily the global one.

2.9 When to stop training (Haykin's criteria)

Backpropagation has no well-defined stopping point; these heuristics are used:

  1. Gradient criterion — stop when the Euclidean norm of the gradient ‖∇E(θ*)‖ is sufficiently small (Kramer & Sangiovanni-Vincentelli, 1989). Drawback: needs the gradient and can take long.
  2. Error-change criterion — stop when the absolute rate of change of the average squared error per epoch is small, typically 0.1 % to 1 % per epoch.
  3. Generalisation criterion — test the network after each iteration (cross-validation) and stop when generalisation performance has peaked (early stopping).

"Stop when the number of epochs exceeds the number of input features" is not a valid criterion.

2.10 Tutorial: why mathematics for AI

  • Linear algebra — vectors, matrices and tensors represent data (images, text embeddings); a layer is a matrix multiply.
  • Calculus — backpropagation is the chain rule; optimisation needs derivatives.
  • Probability & statistics — learning from data, uncertainty, Bayesian inference.
  • Optimisation — efficiency and accuracy of training.
  • Evaluation — accuracy, precision, recall, area under the ROC curve.
  • Also: logic for reasoning, vector-space models for language, scalability for big data.
