Numerical drill — unlimited practice

Every click generates a fresh exam-style numerical. Solve it on paper, then reveal the worked answer.

Mixed self-test (20 questions)

1. Which attack threatens availability?

  1. Snooping
  2. Replaying
  3. Denial of service
  4. Traffic analysis

DoS blocks access to the service.

2. Notarization is a mechanism for:

  1. non-repudiation
  2. confidentiality
  3. availability
  4. routing

A trusted third party records the exchange.

3. gcd(161, 28) =

  1. 14
  2. 7
  3. 1
  4. 28

161 = 5·28 + 21; 28 = 21 + 7; 21 = 3·7.

4. 3⁻¹ mod 26 =

  1. 3
  2. 7
  3. 17
  4. 9

3 × 9 = 27 ≡ 1.

5. The Vigenère cipher is broken using:

  1. meet-in-the-middle
  2. birthday attack
  3. Kasiski test
  4. timing attack

Find the key length from repeated fragments.

6. In DES, the expansion P-box converts:

  1. 32 → 48 bits
  2. 48 → 32 bits
  3. 64 → 56 bits
  4. 56 → 48 bits

To match the 48-bit round key.

7. 02 × 87 in GF(2⁸) =

  1. 0E
  2. 15
  3. 87
  4. 1B

87 = 1000 0111 → shift = 0000 1110 = 0E; MSB was 1 → 0E ⊕ 1B = 15.

8. Which mode turns a block cipher into a counter-based stream cipher?

  1. ECB
  2. CBC
  3. CFB
  4. CTR

CTR encrypts successive counter values.

9. φ(100) =

  1. 50
  2. 60
  3. 40
  4. 99

100 = 2²·5² → (4−2)(25−5) = 2·20 = 40.

10. In RSA, if φ(n) = 40 and e = 7, d =

  1. 23
  2. 17
  3. 3
  4. 33

7 × 23 = 161 = 4·40 + 1.

11. The Rabin cryptosystem requires p ≡ q ≡

  1. 1 (mod 4)
  2. 3 (mod 4)
  3. 0 (mod 2)
  4. 1 (mod 3)

So square roots are C(p+1)/4.

12. The point at infinity O in ECC acts as:

  1. a generator
  2. the inverse of every point
  3. the identity (zero)
  4. a private key

P + O = P.

13. SHA-512 padding for a 896-bit message adds how many zero bits?

  1. 0
  2. 127
  3. 895
  4. 1023

(−1025) mod 1024 = 1023 → total 896 + 1 + 1023 + 128 = 2048 (2 blocks).

14. MD5 produces a digest of:

  1. 128 bits
  2. 160 bits
  3. 256 bits
  4. 512 bits

Four 32-bit words.

15. A MAC cannot provide:

  1. integrity
  2. non-repudiation
  3. data-origin authentication
  4. tamper detection

Both parties share the key, so either could have made it.

16. Diffie–Hellman with p = 23, g = 5, x = 6, y = 15 gives K =

  1. 8
  2. 19
  3. 2
  4. 16

R₁ = 5⁶ mod 23 = 8; R₂ = 5¹⁵ mod 23 = 19; K = 19⁶ mod 23 = 2 = 8¹⁵ mod 23.

17. Kerberos prevents replay mainly with:

  1. timestamps
  2. certificates
  3. compression
  4. Radix-64

Authenticators contain timestamps; clocks must be synchronised.

18. In PGP the message is compressed:

  1. before signing
  2. after encryption
  3. never
  4. after signing, before encryption

So the signature does not depend on the compression algorithm, and encryption works on less redundant data.

19. The SSL message that tells the peer to start using the negotiated keys is:

  1. Finished
  2. ChangeCipherSpec
  3. ServerHelloDone
  4. Alert

A one-byte message in Phase IV.

20. IKE uses cookies to defend against:

  1. replay
  2. man-in-the-middle
  3. clogging (DoS)
  4. birthday attacks

No heavy work until the cookie returns. Nonces → replay; authentication → MITM.

Model question paper (80 marks, 3 hours)

Pattern varies by university; this paper follows the common "short answers + long answers with internal choice" style. Time yourself.

Part A — answer any 6 (6 × 2 = 12)

  1. Differentiate passive and active attacks.
  2. Find the multiplicative inverse of 15 in ℤ₂₆.
  3. What is the avalanche effect?
  4. List the AES transformations used in a round.
  5. State Fermat's little theorem.
  6. Define collision resistance.
  7. What is a session key?
  8. Differentiate AH and ESP.

Part B — answer any 4 (4 × 5 = 20)

  1. Explain the X.800 security services.
  2. Encrypt "MEET ME" using Playfair with keyword "CRYPTO".
  3. Solve x ≡ 1 (mod 5), x ≡ 2 (mod 7), x ≡ 3 (mod 9) using CRT.
  4. Explain the Diffie–Hellman protocol and the man-in-the-middle attack.
  5. Explain CBC mode with a diagram.
  6. Explain the X.509 certificate format.

Part C — answer any 4 (4 × 12 = 48)

  1. (a) Explain the extended Euclidean algorithm and find gcd(84, 320), s and t. (b) Solve 14x ≡ 12 (mod 18).
  2. Explain the structure of DES with the round function and key generation.
  3. Explain AES: state, four transformations and key expansion.
  4. Explain RSA with an example (p = 7, q = 11, e = 13, M = 9) and discuss attacks.
  5. Explain SHA-512 in detail.
  6. Explain Kerberos with a neat diagram.
  7. Explain SSL architecture and the Handshake protocol.
